# Security policy

## Reporting a vulnerability

Email hello@stacktician.com. Do not open a public issue for a vulnerability. You will get an
acknowledgement within five working days and a fix or a published advisory once the issue is
understood.

## Scope

The current milestone is a deliberately naive baseline: its known weaknesses are listed in
[ADR 0007](docs/adr/0007-a-deliberately-naive-baseline-first.md) and in the controls table of
the [README](README.md#controls). Reports about those are welcome but already tracked;
anything else is new and wanted.

## Supported versions

Only `main` is supported. There are no release branches yet.
